# 04: 健康档案进证据快照

**What to build:** 每条导诊记录的证据快照里多一个档案节点，存下"**系统当时看到的档案**"（当时的待注入文本 + 检索用串 + 结构化档案内容）。患者随后改档案，**旧记录的档案快照不变** —— 回放与审核看到的永远是当时那一份。

这条不是可选项：档案可变，而导诊记录不可改。不存快照，患者今天删掉"糖尿病"就能让历史记录的推荐理由当场失真，等于变相回改了历史。

**Blocked by:** 02（健康档案进模型上下文）、03（健康档案进检索）
> 排在 03 之后是为了**一次存全**：只依赖 02 的话，快照会缺"检索用串"，03 落地时还得再改一刀。

**Status:** ready-for-agent

- [ ] 证据快照新增档案节点，与既有节点（召回切片、实际检索串、送入模型的上下文摘要）**同构**，落在同一份快照里，**不新增存储**
- [ ] 快照同时包含待注入文本、检索用串、结构化档案内容
- [ ] 填档案 → 导诊 → 修改档案 → 回放旧记录：档案仍是**当时那份**
- [ ] 修改档案**不会**改变任何历史导诊记录的结论、置信度或判断依据
- [ ] 审核侧能看到当时的档案（用于归因"系统当时看到了什么"）
- [ ] 档案为空的记录，快照里档案节点为空 / 缺省，回放不受影响（回归）
