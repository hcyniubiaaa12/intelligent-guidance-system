# 05: 管理员维护慢病标签词表

**What to build:** 管理员能启用 / 停用慢病标签（**只做后端接口，不做管理端页面**）。**停用只作用在入口**——患者端选项里不再出现该标签；但已经保存的档案里仍有它的，照常参与检索用串（与「科室停用只作用在入口、历史记录引用不受影响」同一口径）。词表本身可扩展，照既有医学术语白名单的模式。

**Blocked by:** 01（健康档案可填、可存、可读）

**Status:** ready-for-agent

- [ ] 管理员能列出全部慢病标签（含启用状态）
- [ ] 管理员能新增、启用、停用某个标签
- [ ] 停用的标签**不出现在**患者端选项里
- [ ] 停用的标签**仍然参与召回**（对已保存该标签的档案）—— 与「科室停用」同一口径
- [ ] 停用**不改动**任何已保存的历史档案内容，也不影响历史导诊记录
- [ ] 非管理员访问返回 403
- [ ] 不做管理端页面（明确的范围外）
