# 02: 健康档案进模型上下文 + 推荐卡「已参考健康档案」

**What to build:** 填了档案的患者，导诊时模型能看到他的背景——置信度与结论说明会随之变化（"结合您的糖尿病史，心血管来源的可能性较高"），推荐卡上**另起一行**出现「已参考您的健康档案：糖尿病史、青霉素过敏」，明确标成"健康档案"而不是"知识片段"。

同时主模板写死三条硬约束：档案是背景不是证据；结论必须由知识片段（注号）支撑；**当前症状的信息（部位 / 性质 / 时长 / 诱因 / 伴随）一律仍须追问**——档案只免除既往史 / 过敏史 / 长期用药这三类追问。

本单据落地纯函数「健康档案 →（待注入文本, 检索用串）」并只接上"待注入文本"这一半；检索用串留给 03。**档案不进注号体系**：它是患者自述，不是医学证据。

**Blocked by:** 01（健康档案可填、可存、可读）

**Status:** ready-for-agent

- [ ] 缝一测试覆盖：全空档案 ⇒ 两段均为空串；标签全进两段；自由文本命中词表 ⇒ 进两段、未命中 ⇒ **只进待注入文本**；条数 / 字数超限行为明确
