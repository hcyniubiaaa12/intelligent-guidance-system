# 08: 稳定背景向量召回与按需注入

**What to build:**

稳定背景不做全量注入，而是按当前对话做向量召回：回答前用已经算好的 query 向量，对当前用户的背景记忆做 top-3 相似度召回，超过阈值才进提示词；未命中即完全不可见。带否定句拦截、sticky 2 轮与过期过滤。

完成后：患者说过「我有糖尿病」，谈到相关话题时系统会带上它；谈无关话题时不塞入。

**Blocked by:** 07

**Status:** resolved

- [ ] 背景记忆写入时生成向量并落向量表；只向量化背景，不向量化偏好
- [ ] 向量表按用户与类型过滤；不建 HNSW，顺序扫描足够
- [ ] 回答前复用检索层已经算好的 query 向量做召回，不额外调用 embedding
- [ ] 召回结果按 top-3、余弦阈值（默认 0.70，走运行时配置）过滤
- [ ] 命中项按「相关度降序」进入提示词背景段；未命中项不出现，也不做一行索引兜底
- [ ] 当前消息否定该背景时（「我没有糖尿病」）跳过该条
- [ ] 命中后接下来 2 轮继续注入，避免代词指代时消失
- [ ] 有效期已过的背景不注入
- [ ] 关闭自动记忆时不召回、不注入；健康档案照常注入
- [ ] 向量写入失败可补偿：记录缺向量并异步回填；MySQL 与向量库不长期不一致
- [ ] 测试覆盖：命中、未命中、阈值边界、否定句、sticky、过期、关闭开关
