# 01: 档案退出检索（prefactor）

**What to build:**

把健康档案从检索层摘出去，但保留它作为生成背景与推荐卡「已参考健康档案」行的现状。

完成后：导诊检索回到「主诉向量 + 主诉关键词」两路；档案不再参与召回、不参与融合、不参与精排；档案文本仍进生成提示词。这是后续改 prompt 与记忆注入的前置清理——先让检索层不再有档案通道，后面就不用绕过它。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] 检索请求不再携带档案召回串；档案的向量与关键词两路召回被删除
- [ ] 精排 query 仍只来自主诉改写串，档案没有排序话语权
- [ ] 档案文本仍注入生成提示词；推荐卡「已参考健康档案」行行为不变
- [ ] 证据快照仍能写出当时的档案文本与结构化内容；新快照不再写检索用串，老快照的该字段仍可安全读取
- [ ] 相关检索测试更新为「两路召回」；导诊端到端仍能出结论
- [ ] 不引入新中间件、不改变依赖方向
