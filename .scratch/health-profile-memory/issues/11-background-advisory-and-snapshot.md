# 11: 背景相关提醒与证据快照

**What to build:**

稳定背景命中时只报「相关」，不报「禁忌」；同时把本轮注入的记忆与警报完整写进证据快照，回放时读当时那份快照，不查当前记忆。

完成后：患者有糖尿病，相关话题会出现一句轻量提醒；翻旧记录时看到的是当时注入的记忆与警报，而不是今天改过的记忆。

**Blocked by:** 08、10

**Status:** resolved

- [ ] 命中的稳定背景可产出「与您提到的 X 相关」的相关提醒，不写「禁忌」「不能」
- [ ] 相关提醒必须能指回具体记忆条目；指不回的提醒丢弃
- [ ] 相关提醒与档案硬警报使用不同视觉层级，前者轻、后者重
- [ ] 证据快照新增记忆节点：注入文本、命中条目、相似度、查询串、阈值
- [ ] 证据快照新增警报数组，与结果体下发的内容一致
- [ ] 回放与审核读取快照，不查询当前记忆；缺节点或空节点不报错
- [ ] 测试覆盖：相关提醒文案、无锚点丢弃、快照只写不读、老记录兼容
