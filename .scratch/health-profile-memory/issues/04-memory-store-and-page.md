# 04: 长期记忆存储与记忆页

**What to build:**

建立长期记忆的存储与控制面骨架：新增独立的记忆模块、`user_memory` 与 `user_memory_log` 表；「健康档案」页出现「我记住的」段，先做只读列表，每条显示键、值、患者原话出处与记录时间。

完成后：记忆有地方存、有地方看、有审计；后续抽取与注入都挂在这条骨架上。

**Blocked by:** 02

**Status:** resolved

- [ ] 新增记忆模块，依赖公共层、档案与模型适配层；不依赖对话模块
- [ ] `user_memory` 支持偏好、健康背景、其他背景三类；字段含键、值、检索扩展文本、患者原话、置信度、观察时间、有效期、状态
- [ ] `user_memory_log` 记录每次新增/修改/删除，只追加
- [ ] 记忆页「我记住的」段展示当前用户的启用记忆，带出处与时间；空态说明「还没有记住什么」
- [ ] 列表接口只返回当前登录用户的记忆；游客无入口
- [ ] 偏好与背景的条数上限从运行时配置读取并下发给页面
- [ ] 测试覆盖：按用户隔离、逻辑删除过滤、空列表
