# 06: 记忆管理

**What to build:**

让患者能管住系统记住的东西：编辑一条记忆、删除一条、一键清空、关闭自动记忆。关闭后不再抽取新记忆，旧记忆保留但不再生效；健康档案不受影响。

完成后：记忆页从只读变成可控；患者对「系统记住了什么」有最终决定权。

**Status:** resolved

- [ ] 可一键清空当前用户的全部记忆；需二次确认并说明后果
- [ ] 顶部「自动记忆」开关可开可关；关闭后停止抽取
- [ ] 关闭后旧记忆仍在列表中可见，但标注「已暂停」；健康档案照常显示

- [ ] 测试覆盖：编辑、删除、清空、开关状态持久化、按用户隔离
