# 09: 档案候选与确认流

**What to build:**

把抽取出的、能落进档案字段的健康事实（过敏 / 用药 / 手术）送进「待确认」，而不是直接写档案或写背景记忆。患者可先改再收、可拒绝、30 天未处理自动失效；与已有档案冲突时标出来。未确认的候选永远不进提示词。

完成后：患者说「我青霉素过敏」，记忆页出现一条待确认；接受后写进档案，拒绝后不再重复提议。
