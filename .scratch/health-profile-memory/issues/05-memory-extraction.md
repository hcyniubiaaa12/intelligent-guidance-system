# 05: 记忆抽取管线

**What to build:**

从对话里自动抽取偏好与稳定背景：规则预筛命中后异步调用模型，会话空闲 30 分钟兜底；每会话最多 3 次；抽取结果经校验后写入记忆，带患者原话与审计。

完成后：患者说「我希望你讲慢一点」或「我有糖尿病」，下一次打开记忆页就能看到系统记住了它、是从哪句话记的。

**Blocked by:** 04

**Status:** resolved

- [ ] 规则预筛命中后触发异步抽取，不占用在线导诊线程
- [ ] 会话空闲 30 分钟触发一次兜底抽取；不依赖会话关闭事件
- [ ] 每会话最多 3 次模型抽取，超出不再调用
- [ ] 模型输出偏好与稳定背景两类；每条必须含患者原话与置信度
- [ ] 缺原话或置信度低于阈值的条目直接丢弃，不修补
- [ ] 否定句不产生记忆；当前主诉不作为长期事实；禁止从用药推断疾病
- [ ] 偏好满上限时由模型合并去重；稳定背景满上限时保留并提示用户整理
- [ ] 抽取失败只记警告日志，不重试、不影响本轮对话
- [ ] 测试覆盖：合法 JSON、坏 JSON、低置信度、缺原话、否定句、不推断
