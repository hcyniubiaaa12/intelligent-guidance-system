# 03: 档案时间语义

**What to build:**

让「近期」有真实含义：用药带开始/结束时间，手术带发生时间；超过 12 个月的手术自动不再算「近期手术」，已停的用药不再算「近期用药」。

完成后：患者一年前做的手术不会在今天的回答里被说成「近期手术」；老用户没有出生年时仍能看到旧的年龄段兜底。

**Blocked by:** 02

**Status:** resolved

- [ ] 用药条目支持开始月份与结束月份；结束月份为空表示仍在使用
- [ ] 手术条目支持发生月份；精确到月
- [ ] 手术发生超过 12 个月时，组装文本标为「既往手术」，不再算「近期手术」
- [ ] 用药结束月份非空时，不算「近期用药」
- [ ] 出生年缺失但旧年龄段存在时，档案展示只读的旧年龄段并提示可补出生年
- [ ] 档案组装与证据快照体现时间信息；空时间不阻塞保存
- [ ] 测试覆盖：恰好 12 个月、超过 12 个月、未来日期、空时间
