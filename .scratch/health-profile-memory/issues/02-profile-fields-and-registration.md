# 02: 档案缩表与注册采集

**What to build:**

健康档案从「性别 / 年龄段 / 慢病 / 长期用药 / 过敏」缩成「性别 / 出生年 / 过敏 / 近期用药 / 近期手术」，并在注册时选填性别与出生年。

完成后：患者注册时可以顺手填性别与出生年；打开「健康档案」看到的是窄口径、填得完的一屏；旧的慢病字段保留在库里但不再展示、不再注入；游客仍然没有入口。

**Blocked by:** 01

**Status:** resolved

- [ ] 注册页提供选填的性别与出生年，注册成功后写入该患者的档案
- [ ] 健康档案表单只展示性别、出生年、过敏、近期用药、近期手术，不再显示慢病组
- [ ] 旧的慢病标签与慢病自由文本保留在库中，但表单不展示、生成提示词不注入
- [ ] 档案组装文本按新字段顺序生成；空字段不产生空段
- [ ] 游客态仍无档案入口；档案接口要求登录且只读写当前用户
