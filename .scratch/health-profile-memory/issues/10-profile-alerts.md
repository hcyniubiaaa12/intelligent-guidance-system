# 10: 档案硬警报

**What to build:**

当召回的知识内容与健康档案冲突（例如正文提到患者过敏的药、近期做过的部位/手术）时，产出一条患者可见的硬警报，渲染在结论卡顶部。

完成后：患者有青霉素过敏，某条知识片段提到青霉素，结论卡上会出现一条危险色警示条，而不是只靠模型自觉。

**Blocked by:** 02、07

**Status:** resolved

- [ ] 后端规则做词面匹配：档案的过敏、用药、手术词命中召回正文，产出硬警报
- [ ] 模型可在结论 JSON 中补充警报，但必须带锚点（注号或档案字段），无锚点丢弃
- [ ] 规则警报不可被模型否定；两类警报合并去重，最多 3 条
- [ ] 结论结果体下发警报数组；前端在结论卡顶部渲染危险色警示条
- [ ] 非结论轮次（追问 / 资料回答）不渲染结构化警报，只由提示词要求口头说明
- [ ] 没有冲突时不产生警报，不渲染空警示条
- [ ] 警报文案说清「与您的什么档案项冲突」，不写模糊的「注意」
- [ ] 测试覆盖：过敏命中、手术命中、无冲突、模型无锚点警报、去重与上限
