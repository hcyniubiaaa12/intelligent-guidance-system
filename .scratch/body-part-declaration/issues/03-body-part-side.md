# 03: 哪一侧（左 / 右 / 两侧）

**What to build:** 覆盖层里能选一侧（单选、再点取消），拼出的句子与部位声明都带上方位前缀；**全身性词（皮肤 / 关节）不加前缀**（"左皮肤"没有意义）。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 覆盖层出现「哪一侧」一行，三个选项（左 / 右 / 两侧），**单选**，再点一次取消
- [ ] 句子的部位段与部位声明都带方位前缀；全身性词不加前缀
- [ ] 「已选」区能单独删掉方位（不影响已选部位），也能整体清空
- [ ] 缝一测试：
  - 左 + 腹部 ⇒ 声明 `["左腹部"]`、句子 `左腹部疼，`
  - 左 + 上腹 ⇒ 句子 `左上腹疼，`（组合出来恰是临床规范词）
  - 左 + 皮肤 ⇒ 声明 `["皮肤"]`、句子 `皮肤疼，`（全身词不加前缀）
  - 只选方位不选部位 ⇒ 声明为空、句子为空、不允许提交
- [ ] 真机：选左腹部，句子与声明都带上"左"；再点一次取消后，句子回落
- [ ] 术语表里没有左右词这一点**不构成障碍**——"左腹部 / 左上肢"含部位词，照样命中白名单（真机确认发送后不触发模板追问）
