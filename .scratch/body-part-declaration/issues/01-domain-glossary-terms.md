# 01: 补领域词条：部位声明 / 人体图

**What to build:** 领域词汇表里出现「部位声明」与「人体图」两个词条，并写清它们与既有「部位」（那只是术语白名单里的一个**类别**）和「健康档案」的边界。这是项目自己的规矩：词表未覆盖的新领域概念，先补词条再写代码；也是后面四张票的术语前提。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 新增「部位声明」词条：患者在新会话首条输入之前、于人体图上标明的身体部位；随首条输入提交一次，此后不再变
- [ ] 该词条的 _Avoid_ 写明两处不要混用：不要与「主诉」混用（主诉是患者的自然语言描述，部位声明是结构化选择）；不要与术语白名单里那个叫"部位"的**类别**混用（那是判定用的词表，不是患者的选择）
- [ ] 新增「人体图」词条：前后两面的体表区位图；图上的"形"（哪块区域画在哪）是前端资产，图上的"词"只能来自术语白名单
- [ ] 该词条的 _Avoid_ 写明：不要把器官画进去（器官不是体表位置，让患者自己指"心的位置"等于诱导自我诊断）；"说不清在哪儿"是**出口**不是选项
- [ ] 既有「部位」（术语白名单的类别）那处补一句指向「部位声明」，讲清两者不是一回事
- [ ] 与「健康档案」划清边界：部位声明是**本次就诊**的事实、只随首条输入提交一次；健康档案是**长期背景**、可随时改
- [ ] 词条里的名称能对回代码与接口命名（声明字段、只读接口、覆盖层组件三处命名与词表一致）
