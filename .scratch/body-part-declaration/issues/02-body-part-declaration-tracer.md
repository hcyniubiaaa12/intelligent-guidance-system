## 施工中改掉的四件事（留给后来人）

1. **`watch(() => props.open)` 必须带 `{ immediate: true }`**：组件可能挂载时就是打开的，
   那时 open 从 true 变 true，watch 一次都不触发 ⇒ 词表永远不加载、界面静默退回本地点位。
   不报错、不降级提示，只是"看起来正常但用的是兜底数据"——本仓反复记的那类静默故障。
2. **"取词失败"与"词全被停用"必须分开**：前端一次缓存把后端的即时停用抵消了（管理员停了、
   患者重开仍看到旧的）；而两种空值若合并成一种回落方向，就会犯方向相反的错——
   全停用时回落到全量，等于把管理员刚做的决定当成没发生。现在是三态（loading/ready/failed），
   全停用单独给一句话 + 只留「说不清在哪儿」出口。
3. **竖排布局（图与选栏上下）走过三段弯路**，最终定成「整列一个滚动容器 + 两块各自按内容取高」：
   分高度 ⇒ 图只剩 18px；只给图 min-height ⇒ 选栏被挤成 1px；各自 auto 但父级不滚 ⇒
   图压在底部动作条上面。断点用 `@container` 按**浮层自身宽度**判，不按视口（分屏时视口可能仍很宽）。
4. **`.p-btn` 是 `width:100%`**（表单页脚那个"保存档案"就该通栏），三颗挤一行时必须改回内容宽——
   只写 `align-self: flex-start` 没用，100% 是宽度不是拉伸。
