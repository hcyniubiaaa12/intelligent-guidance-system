# 02: 部位声明走通一次完整链路（追踪弹）

**What to build:** 患者打开人体图（正面 + 背面、全部 13 个区域），点一块 → 该块的部位词落进输入框 → 发出去时带上部位声明 → **模型不再问"哪个部位"**。不带声明的请求，链路行为与今天完全一致。

本期**不含**方位、感觉、必填门禁与快捷词入口——那些是后面三张票。图上"形"是一次给全的数据，交互复杂度才是分期加的。

**Blocked by:** 01（词条）；换皮链的皮肤地基（覆盖层要用的令牌与浮层语言从**那里的 02 号票**来，见 `.scratch/patient-redesign/issues/`）

**Status:** ready-for-agent

- [ ] 后端能按类型取部位词（部位类且启用）：只返回部位词、不混症状词、停用项不返回
- [ ] 只读接口返回部位词数组；管理端停用某词后，患者端选项里立即不再出现它（不等缓存过期）
- [ ] 首轮入参新增可选部位声明字段；**缺省为空时链路行为与今天完全一致**（回归零退化）
- [ ] 主提示词把已声明部位作为已知信息注入，措辞说明"这是患者在人体图上标明的，不必再追问部位"——刻意**不说**"患者的部位是 X"（患者随后可能改掉输入框那句话，"他标过 X"却始终为真）
- [ ] 位置声明纯函数零依赖（不碰框架、不碰网络），输出形状：

  ```
  { locations: string[], sentence: string }
  ```

  （本期 `locations` 即部位词本身）

- [ ] 缝一测试：区域→词映射完整；拼句；**映射里的词越出显式词清单即失败**
- [ ] 缝二测试：带声明 ⇒ 首轮不进模板追问、声明被注入上下文；不带声明 ⇒ 与今天一致；声明只在首轮携带，追问轮不重复注入
- [ ] 缝三测试：按类型取词、停用即时生效
- [ ] 人体图覆盖层落地：正反两面、13 个区域、选中态在图上看得见、已选区可逐条删除
- [ ] 图上只出现术语白名单里已有的词（图内 22 / 全身快捷 2 / 刻意不进图 5）
- [ ] 覆盖层复用共享浮层语言，**不新造一种浮层**
- [ ] 真机：点部位 → 落词 → 发送 → 模型不再问部位；不选部位直接打字依然能正常问诊
