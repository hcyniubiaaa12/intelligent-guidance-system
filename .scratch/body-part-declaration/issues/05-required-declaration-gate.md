# 05: 必填引导：门禁 +「说不清在哪儿」出口 + 常见主诉快捷入口

**What to build:** 新会话的首条输入之前必须先声明部位（输入框是明确的等待态）；「说不清在哪儿 · 直接描述」出口让指不出位置的人照常问诊；五个常见主诉快捷词点一下直接带患者去图上对应区域。

必填的是**这一步动作**，不是"必须点中某个区域"——发烧、乏力、浑身没劲、头晕这类主诉根本指不出位置，没有那个出口这批人会被挡死。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 新会话首条输入前，输入框为**等待态**（灰底 + 一句"先选好位置就能开始说了"），发送不可用
- [ ] 「说不清在哪儿 · 直接描述」出口：点了即解除等待态、声明为空；链路**回落到今天的行为**——这是**接受的降级**，不是待修缺陷
- [ ] **追问轮、只读回放后继续、归档会话续聊一律不拦**；判据与后端「新主诉判定」同口径（会话是否已出结论 / 是否已关闭），且**以后端状态为准**（新会话标识由服务端事件回传）
- [ ] 「+ 新的咨询」之后重新回到等待态
- [ ] 常见主诉快捷词 5 个：肚子疼 → 腹部、头疼头晕 → 头、心慌胸闷 → 胸口、腰背酸痛 → 腰、皮肤起疹 → 皮肤；点了**直接打开图并预选**对应区域
- [ ] **移除「发热咳嗽」**——它对应不了任何体表区域，留着等于绕开必填
- [ ] 位置选错可一键重选，不必退出重进
- [ ] 位置锁定时界面上有一处明确的回执
- [ ] 真机四条：新会话被拦 / 追问轮不被拦 / 出口可用 / 快捷词直达对应区域
