# 04: 常见感觉（选填）

**What to build:** 覆盖层里能点感觉（可多选，含"说不上来"），感觉进句子但**不进部位声明**；不选时句子回落成「不舒服」。

**Blocked by:** 02

**Status:** ✅ 完成（2026-10-07，随工单 02 提前落地——同 03 的判据：选填不拦路，且感觉分支是拼句纯函数的一部分）

- [x] 覆盖层出现「什么感觉」一行：疼 / 胀 / 酸 / 麻 / 灼热 / 绞痛 / 刺痛 / 说不上来，**可多选、选填**
- [x] 感觉**只进句子，不进部位声明**（声明只装部位）
- [x] 「说不上来」是可选项，但**不进句子**——它是"未作答"的显式表达，不是一种感觉；与其他感觉并存时也照样滤掉
- [x] 不选感觉 ⇒ 句子回落成 `<部位>不舒服，`（回落词用「不舒服」不用「疼」——不是所有不适都疼）
- [x] 感觉词是前端自持的：术语表里的症状词全是「部位 + 症状」复合词，没有"绞痛 / 刺痛"这类纯形容词——注释写明为什么（`bodyMap.js` FEELINGS：硬塞进术语表会让它们开始参与信息充足性判定与检索聚合，为一个输入框的便利动判定口径不划算）
- [x] 缝一测试：多选、含"说不上来"、完全不选、与方位组合——全部钉住
- [x] 真机：腹部 + 绞痛 ⇒ `腹部绞痛，`；只选腹部 ⇒ `腹部不舒服，`（门禁 e2e 第②③步实测）
