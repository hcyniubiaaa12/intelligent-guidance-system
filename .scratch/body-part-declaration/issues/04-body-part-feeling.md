# 04: 常见感觉（选填）

**What to build:** 覆盖层里能点感觉（可多选，含"说不上来"），感觉进句子但**不进部位声明**；不选时句子回落成「不舒服」。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 覆盖层出现「什么感觉」一行：疼 / 胀 / 酸 / 麻 / 灼热 / 绞痛 / 刺痛 / 说不上来，**可多选、选填**
- [ ] 感觉**只进句子，不进部位声明**（声明只装部位）
- [ ] 「说不上来」是可选项，但**不进句子**——它是"未作答"的显式表达，不是一种感觉
- [ ] 不选感觉 ⇒ 句子回落成 `<部位>不舒服，`
- [ ] 感觉词是前端自持的：术语表里的症状词全是「部位 + 症状」的复合词，没有"绞痛 / 刺痛"这类纯形容词——这一排无法与后端同源，**注释里写清为什么**
- [ ] 缝一测试：多选、含"说不上来"、完全不选、与方位组合
- [ ] 真机：腹部 + 绞痛 ⇒ 句子 `腹部绞痛，`；只选腹部不选感觉 ⇒ `腹部不舒服，`
