# 08: 悬停提示移出人体

**What to build:** 悬停 / 聚焦 / 按触某一块时，这块的名称显示在**图上方固定的那一行**（原本写"点一下不舒服的位置"的位置），SVG 内部不再画任何文字气泡。

现在的气泡画在图内部、固定在被点区域上方 22 单位处，宽度按字数推算。桌面渲染尺寸下它宽约**图宽的 38%**——因为小尺寸下文字被反向放大了 1.5–1.7 倍，于是悬停"腹部"时它盖住的正是"胸部"。提示移出后，人体上不会再有文字遮挡；没有指向时那一行回落显示引导语。

**排在 07 之后**：提示移出之后，图外那一行显示的就是区域的**命名**——命名没换成「腿」之前，槽里会显示"右大腿"，等于把错位从图内搬到图外。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 人体图内**不再绘制任何文字气泡**（渲染后图内不存在气泡节点）
- [ ] 悬停 / 聚焦 / 按触某一块时，图上方那一行显示该区域的命名
- [ ] 松开 / 移出 / 失焦后回落显示引导语，不留空白
- [ ] 名称槽**不加** `aria-live`：聚焦某块时不会被重复播报一次
- [ ] 触屏：按住显示名称、松开回落
- [ ] 图下缘的左右方位标注保持可见，且不与人体重叠
