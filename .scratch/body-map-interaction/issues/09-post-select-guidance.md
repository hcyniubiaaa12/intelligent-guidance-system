# 09: 点完图之后知道该干什么

**What to build:** 点完一块，界面明确告诉患者"现在该看哪儿"。

- 侧栏「具体位置」的标题直接写**该区域实际会记下的词**——「已记录：腿 · 可改成下肢」，而不是区域展示名"下肢"（这两者本来就是两回事，见 `CONTEXT.md` 的「图上命名」）；
- 细分词里**当前生效的那一颗**有可见标记，与普通"已选"区分得开；
- 点选后侧栏对应段做一次**明显的高亮**（现在只有 0.2 秒的背景脉冲，患者感知不到）；
- **窄屏下把该段自动滚进视野**——现在窄屏上细分词在图下方，点完常常根本不在视野里，患者以为"点了没反应"。
