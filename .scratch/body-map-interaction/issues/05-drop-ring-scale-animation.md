# 05: 去掉"正在编辑"环的缩放动效

**What to build:** 点选某一块时，标示"正在编辑"的描边环不再"缩一下"。它现在带一个 1.025 → 1 的缩放动画（实测缩幅 2.44%、时长 0.4 秒），而且**每次点击都会重放**——因为它的重挂载键跟着"当前正在编辑的区域"变。这张票删掉这个几何动效，**以及为它存在的那套重挂载机制**。

环本身**保留**：它仍是"正在编辑"与"已选"的区分手段，只是改由描边颜色与投影表达。此后所有点击反馈一律只允许"颜色 / 描边粗细"这类**不改变几何**的手段。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 点选后该环的动画名为 `none`
- [ ] 环的包围盒在点选后全程不变（取两个时刻比对，不再出现 1.025 → 1）
- [ ] 环仍然可见、仍能区分"已选"与"正在编辑"
- [ ] 为"重放动画"而存在的重挂载机制已移除，没有留下零消费者的代码
