# 12: 方位改成"每块自带一份"——点哪儿记哪儿，互不覆盖

**What to build:** 把方位从"**全局一份**"改成"**每块自带一份**"。

起因（用户真机点的）：点左上肢 → 想改成右侧/两侧时，怎么点都对不上。四轮 grill 之后定位到根因不是 UI，而是**模型**：现在 `side` 是全局一个值，`declarationLocations` 把它前缀到**所有**已选部位上，于是"点另一块"必然要么覆盖、要么被覆盖——患者说的"每一块自己记自己的"在模型里根本表达不出来。

用户给的目标序列（本票的验收基准）：

```
点左上肢  →  左上肢
点右上肢  →  两侧上肢        （同一块点两个半边 = 两边都疼）
点左腿    →  两侧上肢、左腿   ← 关键：腿记它自己的「左」，上肢的「两侧」不被冲掉
```

提交物形状**不变**（`parts` 本来就是每项自带前缀的字符串数组，如 `["两侧上肢","左腿"]`），后端一行不改。

**已定的规则**（四轮 grill 的结论，逐条都有据）：

1. **每块一份方位**：`sides` 以**区域 id** 为键（不是词——换细分词"腹部→上腹"时方位不能丢）。全身词（皮肤 / 关节）永远不带方位。
2. **图上的点击规则**（只此一份实现，`clickOutcome`）：
   - 未选这块 → 选中，方位 = 点的那半边
   - 已选，**同一侧再点一次 → 直接取消这块**（用户明确要求）
   - 已选，点**另一半边** → 这块记「两侧」
   - 已选，当前是「两侧」→ 点任一半边 ⇒ 只剩另一半边（点右→左、点左→右）——规则使然，已向用户点名并获接受
   - 已选，当前未标 → 点哪半边记哪侧
   - 中心块（腹/胸/头…，没有左右半边）→ 点一下只增删部位，方位得走下面第 3 条
3. **「哪一侧」三颗常驻**（甲方案）：实心那颗 = 生效；**作用于"正在编辑的那一块"**（标题报 `上肢 · 左侧`，作用于谁就报谁）；点实心那颗 = 改回"不标"。这样**中心块也能带方位**——点腹部、再点左侧 ⇒ `左腹部`（"上腹 + 左 = 左上腹"那条拼法不能丢）。
4. **取消一块 = 词与它的方位一起收走**（`sides` 里不留孤儿，否则重新选中它会带着旧方位回来）；一块都没选时 `act` 也清空（工单 11 的口径）。
5. 已选栏**不再单列一条「左侧」胶囊**（方位已经长在部位那条里了）。

**取代**：工单 10 的"「哪一侧」只显示生效的那一颗"（本票改回三颗常驻）、以及本轮 grill 中作废的"全局方位谁覆盖谁"那几问（Q3/Q6）。

## Comments

实现完成（集成分支 `feat/body-map-interaction`）。

- **数据模型**：`state.side`（全局一个值）→ `state.sides`（**以区域 id 为键**）。为什么按区域不按词：换细分词（腹部→上腹）时方位不能丢。新增/改写的纯函数——`regionOfWord` / `sideOfRegion` / `sideOfWord` / `setRegionSide` / `clickOutcome`；`declarationLocations` / `sentence` / `pickedLabel` 的第二个参数从 `side` 字符串变成 `sides` 映射；`removeWord` 现在**连方位一起收走**。
- **图上点击规则只此一份**：`clickOutcome({ selected, current, clicked })` 返回 `{ keep, side }`，覆盖层只管照做——未选 ⇒ 选中并按点的那半边定方位；同一侧再点 ⇒ 取消；点另一半边 ⇒ 两侧；从两侧点任一半边 ⇒ 只剩另一半边；中心块 ⇒ 只增删部位。
- **验证**：`cd frontend && npm run check` → **124 条全绿**（从 97 涨上来，新增 ⑦ 段专治方位与点击规则）；真机探针 **40 条**（桌面 1440×900 与窄屏 430×900 各一遍），其中 5 条是本票的核心：
  - 点左上肢 ⇒ `左上肢不舒服，`（`左侧`实心）
  - 再点右上肢 ⇒ `两侧上肢不舒服，`（同一块升成两侧）
  - **再点左腿 ⇒ `两侧上肢、左腿不舒服，`** ← 用户给的目标序列，上肢的两侧不被冲掉
  - 同一侧再点一次 ⇒ `两侧上肢不舒服，`（腿被取消）
  - 点腹部 + 点「左侧」⇒ `左腹部不舒服，`（中心块也能带方位）
- **已选栏不再单列一条「左侧」**：方位长在部位那一条里（`两侧上肢` / `左腿`），再列一条是同一份事实写两遍。
- 本票**退回**工单 10 的"「哪一侧」只显示生效的那一颗"（改回三颗常驻——三颗都在才保证右侧/两侧永远一点可达）。
