# 04: 人体图高度与页脚解耦

**What to build:** 患者点选任意一块，**人体图的渲染尺寸完全不变**。当前桌面上点选会让图**永久**缩小约 11.6%（实测渲染高 396.39 → 350.39，宽 284 不变）：点选后页脚多出一行「已选」，页脚高 105 → 151，逐级把图区挤矮。这张票把**图高改成只由浮层/视口高度决定**（定高 + 固定宽高比），不再占用剩余空间；空间不够时由**图区自身滚动**，而不是把图压小。窄屏已经是这个形态（图高写死，所以从不复发），把它上移到桌面。

**Blocked by:** None（可立即开始）

**Status:** resolved

- [x] 窄屏 430×900 同样完全相等（这是回归项，不能被这次改动弄坏）
- [x] 浮层高度不足时是图区自身滚动，图不被压小
- [x] 用**逐子元素高度比对**确认点选前后图区各直接子元素高度无变化——这是证明"耦合已断"的手段，目视量不出 46px 这个量级

- **补记（收口校准）**：照抄窄屏的 `min(62vh, 460px)` 在 1440×900 上会让图区溢出 64px——「全身性不适」那一排默认就落在折线以下、要滚一下才看得见。所以加了 `100dvh - 510px` 这一项（= 浮层里除图之外的固定开销：头 + 页脚 + 图例 + 全身性那排 + 间距 + 内边距，按实测反推），另加 220px 地板防极矮视口把图压没。收口后 **1440×900 / 1280×800 / 1600×1000 溢出均为 0**。
