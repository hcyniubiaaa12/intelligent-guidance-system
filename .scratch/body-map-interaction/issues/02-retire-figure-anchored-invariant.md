# 02: 退掉「图上的词必须来自术语表」这条旧不变式

**What to build:** 把这条约束的**锚点从"图"移到"句子"**。

现在文档里的写法是「**图上**可选的词只来自术语表」。这是个**以图为锚**的旧表述：它把话说在"图上写什么"上，于是任何出现在图上、却不在术语表里的字，看起来都像越界——图上的「腿 / 脚 / 髋」会被误判，而"这块地方叫什么"到底该由谁定，也一直没有依据。

而它真正要守的是另一件事：**拼出来的句子必须含术语词**，否则过不了信息充足性门槛。那是关于**句子**的要求，与"图上怎么写"无关。锚点一移，两件事各自归位：

- **句子**：必须命中术语词（信息充足性门槛的唯一要求，保持不变）
- **图上的字**：命名是前端资产；图上可选（会被写进句子）的词才受术语表约束

影响：票 07 要做的就是"图上的字改成可选词"，一句以图为锚的硬约束会把它绊住。所以这条先退。
