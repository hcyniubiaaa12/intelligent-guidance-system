# 02: 患者端皮肤地基：令牌 + 共享部件 + 浮层语言

**What to build:** 患者端的令牌集与共享部件（气泡、卡片、按钮、标签、输入区、步进条）整体换到方向 04，并把**浮层语言提升为共享部件**——使它不再是某一页的私产，任何页面（含部位声明的覆盖层）都能直接复用。

**为什么把浮层并进来**：部位声明的覆盖层要靠它。并进来之后，那件事只等这一票，不必等整页换完。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 令牌值与设计文档的令牌表**逐条一致**，无自造色、无自造字号
- [ ] 无硬编码颜色（令牌定义处除外）；无"引用了但没定义"的令牌
- [ ] 共享部件全部换到新语言：消息气泡、卡片、按钮、标签、输入区、步进条
- [ ] **浮层语言成为共享部件**：抽屉与覆盖层的遮罩、容器、关闭方式、进出节奏收在一处，页面不各自实现
- [ ] 键盘焦点可见（`:focus-visible`）；`prefers-reduced-motion` 下无动效
- [ ] **未迁移的页面照常能跑**——中间态允许视觉不统一，但不许坏（构建通过 + 各页可打开可用）
- [ ] 真机：任取一个引用了共享部件的页面，看到的是新皮肤
