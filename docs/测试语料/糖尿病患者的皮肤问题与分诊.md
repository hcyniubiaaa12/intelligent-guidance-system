# 糖尿病患者的皮肤问题与分诊

## 一、为什么糖尿病患者容易出现皮肤问题

长期血糖偏高会降低皮肤屏障功能、影响微循环与免疫防御，皮肤感染、瘙痒与皮肤过敏的发生率都高于一般人群。血糖控制不佳时，皮疹更容易反复，破损处也更难愈合。

## 二、皮肤过敏与荨麻疹的区分

皮肤过敏多表现为接触部位的红斑、丘疹与瘙痒，常与接触物、食物或药物相关，去除诱因后多可缓解。荨麻疹表现为风团，来去迅速，单个皮疹通常在 24 小时内消退且不留痕迹，可伴眼睑或口唇肿胀。两者都可能反复发作，鉴别要点在于皮疹形态、持续时间与诱因。

## 三、需要立即就医的危险信号

皮疹伴呼吸困难、喉头紧缩感、声音嘶哑、头晕或血压下降，提示严重过敏反应，应立即前往急诊。皮疹伴高热、大面积水疱或皮肤坏死，也应尽快就诊，不要自行处理。

## 四、就诊科室与就诊前准备

以皮疹、瘙痒、风团为主要表现且没有全身危险信号的，首诊皮肤科；若同时存在血糖控制不佳、反复皮肤感染，就诊时应一并告知医生糖尿病病史。就诊前可整理这些信息：皮疹出现的时间与部位、是否接触过新的食物或药物、已知的过敏史、近期血糖情况与正在使用的药物。不要自行加用激素类药膏，尤其是面部与破损皮肤。
